# Handwritten Digit Recognition 1.0

Handwritten Digit Recognition 1.0 is the original Python experiment for training neural-network models to identify handwritten digits. The repo contains training scripts, digit datasets, and several saved Keras model artifacts from different training attempts.

## Features

- Python scripts for experimenting with handwritten digit recognition.
- Multiple saved Keras model artifacts.
- Local digit data folders for training/testing workflows.
- Early model iteration history that led into the later web app version.

## Tech Stack

- Python
- Keras model artifacts
- Local image/digit data

## Project Structure

- main.py - primary experiment script
- new-model.py - additional model training/iteration script
- digits and digits2 - local digit data folders
- *.keras - saved model artifacts

## Relationship to Version 2.0

This repo is the first model-building version. The newer project, Handwritten-Digit-Recognition-2.0, wraps a trained model in a Next.js/FastAPI web app so users can upload images and get predictions from the browser.

## Status

Historical AI/ML prototype. Keep this repo as the model-experiment foundation and point portfolio visitors to version 2.0 for the more polished web app experience.
